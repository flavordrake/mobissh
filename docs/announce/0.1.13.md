## Reddit

**Title:** MobiSSH 0.1.13: an Android SSH/SFTP client built around tmux and coding agents (open source)

**Body:**

MobiSSH is an open-source SSH and SFTP client for Android that I built to run Claude Code and other terminal agents from my phone over Tailscale. It connects straight to your host's sshd; there is no relay and nothing to install on the server.

What it does that a plain terminal app doesn't:

- URLs, file paths and commands in the output are highlighted. Tap a URL to copy it, tap a path to open it in the built-in file browser, tap a command's gutter chip to copy it.
- The SFTP browser opens Markdown, PDF, images and code, and you can edit a Markdown file and save it back over SFTP.
- With `set -g mouse on`, a swipe scrolls tmux's history and a sideways swipe changes window.
- A compose box where swipe typing and voice dictation work, plus a keybar with Esc, Ctrl, Tab and arrows.

New in 0.1.13:

- Iosevka is now one of the bundled terminal fonts.
- A bad SSH key or wrong passphrase is refused when you add it, and adding a key from the profile editor takes 5 taps.
- Restoring an encrypted backup lists every entry it skipped and why.
- Bug reports no longer include your hostnames or usernames; unsent reports stay off cloud backup and expire after 30 days.

Limits: Android only (arm64 APK from GitHub releases, not on the Play Store). The in-app updater only works against my own install host, so you update by installing the next release.

Repo and APK: https://github.com/flavordrake/mobissh
